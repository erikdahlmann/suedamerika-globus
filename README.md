# Wirtschaft in Südamerika – 3D-Globus

3D-Globus mit Wirtschaftsdaten der zwölf Staaten Südamerikas für die Jahre 1980, 1990, 2000, 2010 und 2024.
Kennzahlen: BIP pro Kopf, BIP gesamt, Einwohner, Wachstum, Inflation, Arbeitslosigkeit. Klick auf ein Land öffnet den Steckbrief.

Live: https://erikdahlmann.github.io/suedamerika-globus/

## Quellen und Lizenzen

- Wirtschaftsdaten: Weltbank, World Development Indicators (CC BY 4.0); Lücken bei der Inflation: IWF, World Economic Outlook.
- Ländergrenzen: world-atlas (Natural Earth, gemeinfrei).
- Erdtexturen: Beispielbilder von three-globe (NASA Blue Marble, gemeinfrei).
- 3D-Darstellung: globe.gl (MIT-Lizenz).

Alles liegt lokal in `lib/`, die Seite lädt nichts von fremden Servern und öffnet auch per Doppelklick.
Zeitreihe neu bauen: `python3 _werkzeuge/bau_zeitreihe.py`.

Erstellt mit Claude Opus 5.5. Impressum und Datenschutz: https://erikdahlmann.github.io/impressum.html
